# Предметная область Secunda

Этот словарь задаёт имена понятий для кода, тестов и архитектурных решений. Маршруты и формат сообщений описаны в `docs/openapi.yaml`; описание архитектуры и эксплуатационных решений — в `README.md`.

| Понятие | Значение | Представление в коде |
|---|---|---|
| Пользователь | Зарегистрированный человек с именем, email и хешем пароля. JWT содержит его ID, но не роли в командах. | `entity.User` |
| Команда | Область совместной работы и видимости задач. Имеет одного владельца. | `entity.Team` |
| Членство | Связь пользователя с командой и роль `owner`, `admin` или `member`. Не содержит состояние списка задач или кеша. | `entity.Membership` |
| Приглашение | Немедленное добавление зарегистрированного пользователя в команду. Повторное приглашение не меняет роль. | `usecase.Team.Invite` |
| Задача | Работа внутри одной команды: название, описание, статус, автор, необязательный исполнитель, версия и время закрытия. | `entity.Task` |
| Версия задачи | Номер состояния одной задачи. Клиент передаёт ожидаемую версию; устаревшая запись отклоняется. | `Task.Version` |
| Изменение задачи | Переход от заблокированного текущего состояния к новому. Права и новые значения определяются бизнес-правилами; запись включает историю и увеличение ревизии списка. | `usecase.Task.Update`, `usecase.TaskWriter` |
| История задачи | Старые и новые значения полей, автор изменения и время. JSON-значения должны сохраняться без потери точности, включая целые `int64`. | `entity.History`, `entity.Change` |
| Комментарий | Сообщение участника команды к задаче. Не изменяет версию задачи и ревизию списка. | `entity.Comment` |
| Ревизия списка задач | Общий для команды номер состояния списка. Увеличивается в MySQL при создании или изменении задачи и входит в Redis-ключ. Отличается от версии отдельной задачи. | `teams.task_revision` |
| Позиция страницы | Исключительная граница по ID последней возвращённой записи. Публичный курсор подписан и привязан к пользователю, ресурсу и фильтрам; не даёт прав доступа. | `entity.Pagination.AfterID`, `entity.Page.NextID` |
| Доступ к списку задач | Результат чтения членства текущего пользователя и актуальной ревизии команды. Отсутствующее членство даёт `ErrNotFound` до обращения к кешу. | `usecase.TaskListAccess` |
| Отчёт команды | Статусы задач, топ исполнителей за 30 дней, среднее время закрытия и количество комментариев. Доступен владельцу и администратору. | `entity.TeamStats` |

Автор задачи может менять все разрешённые поля, исполнитель без авторства — только статус. Эти права действуют только при существующем членстве. Владелец и администратор могут редактировать любые задачи своей команды.
